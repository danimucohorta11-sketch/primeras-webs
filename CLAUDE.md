# primeras-webs

Repositorio con varias webs de clientes (Talleres Chicote en la raíz, `nou-look-web/`, `peluqueria-bea-web/`, `perruqueria-sonia-web/`, `norventis-crm/`).

`peluqueria-bea-web/` (fotos reales, reserva en Booksy) y `perruqueria-sonia-web/` (fotos de stock, cita por WhatsApp) son las webs de peluquería más completas: úsalas como plantilla para las siguientes, pero dale a cada una identidad propia (colores, tipografía, portada).

La rama principal del repositorio es `claude/cool-volta-vu1hhz` (no `main`): Vercel lee esa.

## Webs de peluquería
Antes de diseñar o rehacer cualquier web de peluquería, leer `docs/REFERENCIAS-PELUQUERIAS.md`:
son las referencias que eligió el cliente (Llongueras y Marco Aldany). Se toman como inspiración, sin copiar contenido ni marca.

## Previsualizar webs para el cliente
Cuando el cliente pida "ver" o "abrir" una web, NO la subas a Vercel (lo hace él). Dale el enlace de la página de Claude (artifact).
- Peluquería Bea: https://claude.ai/artifact/SDosAiS5AiG6QnGCJzik9d — cómo regenerarla en `peluqueria-bea-web/docs/PREVIEW.md`.
- Perruqueria Sònia: https://claude.ai/artifact/FVD2fgcRVg7pu1JhESrLnW — cómo regenerarla en `perruqueria-sonia-web/docs/PREVIEW.md`.
