# primeras-webs

Repositorio con varias webs de clientes (Talleres Chicote en la raíz, `nou-look-web/`, `peluqueria-bea-web/`, `norventis-crm/`).

`peluqueria-bea-web/` es la web de peluquería más completa: úsala como plantilla para las siguientes.

## Webs de peluquería
Antes de diseñar o rehacer cualquier web de peluquería, leer `docs/REFERENCIAS-PELUQUERIAS.md`:
son las referencias que eligió el cliente (Llongueras y Marco Aldany). Se toman como inspiración, sin copiar contenido ni marca.
